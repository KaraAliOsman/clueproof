## Redactions in the public web copies

The web copies in `docs/assets/photos/` pixelate values that belong to real people, following Clueproof's own rule of naming a clue without repeating it: the license plates in S06 (the subject car and two background cars), the barcode in S07, the remaining card digits in H02, the Wi-Fi password in H04 and the remaining postal code in S10. The full-resolution test copies in `tests/photos/` are kept as published on Wikimedia Commons, because the Skill must find these clues on the NAS; use them only for testing.
