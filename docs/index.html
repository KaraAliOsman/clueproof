            Marked once, settled every public check after

            The Keep private tag is memory the NAS keeps in File Manager. It says a photo is sensitive, never why.

            1. You approve one plan

              Then the NAS asks its own approval for each write.

            2. file-agent adds the tag

              Only on Keep private photos that do not carry it yet.

            3. The next check knows

              For Public and Marketplace, tagged photos are Keep private at once. For Private they are read normally.

            Nothing leaves the NAS

            A cloud check would upload exactly what you are trying to protect.

            • No external calls

              Every reading runs on the NAS’s own experts. Nothing is uploaded.

            • Types and positions only

              It says “house number, top right”, never the number itself. No place names.

            • Payment cards never read

              Reported only as “payment card visible”.

            • Read-only until you approve

              One plan for you, then the NAS asks again for each write.

            • Photos stay as they are

              It never edits, moves, deletes or shares a photo, or changes permissions.

            • Only what is yours

              Your library and the albums you shared. Never albums shared with you.

            • A second look, not a guarantee

              Tiny text, reflections and context only a person knows can slip through.
