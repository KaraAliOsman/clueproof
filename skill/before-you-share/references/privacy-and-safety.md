# Privacy and safety rules

Before You Share looks at the most revealing parts of a family's photos. These rules apply to every mode and every step.

## The check must not leak

- The Skill makes no network calls, sends no messages, creates no public links and uploads nothing. All analysis is delegated to the NAS's own registered experts.
- Experts are asked for types and positions, never for the text, numbers, codes, names, addresses or coordinates they see. Nothing of that kind is written to chat, album names or tags, even if an expert returns it by mistake.
- Payment cards are reported only as "payment card visible". Security codes, PINs and passwords are never read out, even when the user asks; the user can open the photo.
- Location findings say only that GPS data is stored; place names and coordinates are never shown in chat or saved.

## Whose photos

- Check only photos in the current user's personal library, folders the user names, and albums the user created and shared.
- Tags are added only to files the current user can change.
- Never analyze albums or photos that other people shared with the user; their privacy is theirs to manage.
- Face recognition is used only for personal rules, and only for the person the rule names; the names of other people in a photo are never requested.

## Writes need consent

- Everything is read-only until the user approves one consolidated plan that lists the album and the tagged files.
- The NAS may then ask its own approval for each write; the Skill waits for it, never rewords or splits a task to avoid it, and never recommends a broader approval option.
- The Skill never moves, edits, crops, blurs, deletes or shares a photo, and never changes album sharing, folder permissions or metadata. Fixes are suggestions for the user; official steps come from Step 11.

## Honesty about limits

- A verdict is a second look, not a guarantee. Say once, briefly, that tiny text, reflections and context only a person would recognize can slip through.
- A photo is never called Clear when a reading or the metadata did not complete for it.
- The Keep private tag shows in File Manager that a photo is sensitive, never why; tell the user so before tagging.
- Never present a guess as a finding, never drop a finding an expert returned, and never claim that photos were fixed, cleaned or protected.
- Never present the Skill as an official UGREEN feature.

## Sensitive moments

- If an expert asks for a password, PIN or account access, do not relay it; tell the user to open the item themselves.
- Keep the tone factual and calm. Do not lecture about sharing; give the finding, its position and one fix.
