# Narration with ElevenLabs

The narration is generated by the team with ElevenLabs and dropped into the film. Generate each line as its own clip, so timing can be matched to the picture.

## 1. Voice

Pick a voice from the Voice Library, or create one with **Voice Design** using this description:

> A calm, confident narrator in their mid-thirties with a warm, slightly low voice and a neutral American accent. Close-mic, intimate and unhurried, like a premium technology keynote film. Quiet authority, a hint of a smile, never salesy. Clean studio recording, no reverb.

Library search terms that fit: "narration", "documentary", "calm", "warm", "deep", "storyteller".

## 2. Model and settings

Use **Eleven Multilingual v2** for consistent tone across clips:

| Setting | Value |
| --- | --- |
| Stability | 50% |
| Similarity | 80% |
| Style exaggeration | 15% |
| Speaker boost | On |
| Speed | 0.95 |
| Output | MP3 44.1 kHz 192 kbps, or WAV |

If you prefer **Eleven v3** (more expressive), keep the same text, remove the `<break>` tags (v3 does not use them; use the ellipses already in the text) and add at most one audio tag where marked.

## 4. Checks before sending the clips

- Each clip is within half a second of its target length; if a clip runs long, raise Speed to 1.0 rather than cutting words.
- "UGREEN" is pronounced "you-green", and "Clueproof" as "clue-proof" with stress on "clue". If the model stumbles, write "you green" or "Clue-proof" in the text.
- No background noise, no music in the clips; the film adds the music bed.
- Put all 16 files in `docs/launch-film/vo/` and the film can be re-rendered with the narration mixed under the music, ducked by 8 dB during speech.
